❓ TROUBLESHOOTING:

Q: The auto-repair dialog doesn't show up
A: Restart Unity once. The script will run on next startup.

Q: Unity is stuck on "Importing..."
A: This is normal! Package reimport takes 5-10 minutes. Be patient.

Q: Still getting errors after repair
A: Very unlikely, but if so: Delete Library folder manually while Unity
   is closed, then reopen.

Q: MCP Setup asks for Python or uv
A: Install Python 3.8+ from: https://www.python.org/downloads/
   Install uv from: pip install uv

Q: MCP Bridge won't start
A: Check Unity Console for errors. Verify Python and uv are installed.
   Try "Rebuild MCP Server" in the MCP window.
